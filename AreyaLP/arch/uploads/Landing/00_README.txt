КАК ЗАГРУЗИТЬ В CLAUDE DESIGN

1. Открой Claude Desktop → Claude Design → новый проект.
2. Прикрепи файлы (кнопка + / перетащить):
   01_ПРОМПТ_для_Claude_Design.txt   — НЕ прикрепляй, а открой и вставь текст в поле сообщения
   02_ТЗ_полное.html                 — прикрепить (полное ТЗ с дизайн-системой и структурой)
   03_hero_Екатерина.jpg             — прикрепить
   04_ТЕКСТЫ_сайта.md                — прикрепить (все тексты дословно)
   05_отзывы.csv                     — прикрепить (заполнить имена/точки А-Б, когда Екатерина пришлёт скрины)
   photos/                           — папку с фото с мероприятий (переименуй файлы event_01.jpg … event_20.jpg)
3. Отправь промпт. Дождись первой версии.
4. Итерации: «сделай карточку Master темнее», «увеличь фото в hero» и т.д. — по одному изменению за сообщение.
5. Экспорт: Claude Design → Export/Download HTML → передать на VPS.

Если Claude Design не умеет читать .md/.csv — вставь их содержимое текстом следом за промптом.
