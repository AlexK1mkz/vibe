# ТЗ для Claude Design — блок «Результаты» (карусель кейсов) на сайте Екатерины Ареи

## 1. Задача

Собрать секцию-карусель из **14 карточек кейсов** по уже утверждённому визуальному шаблону (см. `Шаблон_карточки.png` и `Шаблон_секции.png`, если приложены; описание ниже). Все тексты, фото и ссылки — готовые, брать из этого файла. Ничего не придумывать и не менять формулировки цифр.

Данные также лежат в таблице `Кейсы_заполнено.xlsx`, лист `05_отзывы` (колонки `name / niche / before / after / quote / img / url`) — можно читать напрямую оттуда, этот файл — человеко-читаемая версия того же.

## 2. Заголовок секции

- Надзаголовок (маленькие капс-буквы, золотистый): **РЕЗУЛЬТАТЫ**
- Заголовок (крупный serif, как в макете): **Что меняется в жизни и доходе тех, кто прошёл путь с Екатериной**
  - Запасные варианты, если длинно: «Результаты, которые говорят сами за себя» / «Люди, которые прошли путь с Екатериной — и их точка Б»
- Подзаголовок «Мастер-группа Екатерины Ареи, 2021–2024» — **УДАЛИТЬ**. Никаких дат и отсылок к прошлому. Вместо него можно оставить пустоту или одну строку: **«14 историй: было → стало. Каждая — с ссылкой на первоисточник»**.
- Справа — стрелки карусели ‹ ›, снизу подсказка «Смахни, чтобы читать дальше →» (оставить как в макете).

## 3. Структура карточки (как в макете)

```
┌────────────────────────────────────┐
│ (круг с номером)  Имя Фамилия      │  ← круг заменяем на КРУГЛОЕ ФОТО (аватар)
│                   ниша (серым)     │
│ ────────────────────────────────── │
│ БЫЛО                 СТАЛО         │  ← лейблы капсом; СТАЛО — золотистым
│ точка А              точка Б       │  ← точка Б — жирнее/темнее точки А
│ ────────────────────────────────── │
│ «цитата из поста»  (курсив serif) │
│ Открыть отзыв ↗                    │  ← ссылка на пост Instagram, target=_blank
└────────────────────────────────────┘
```

Правила:
- **Фото**: круглое, 56–64 px в карточке, на месте цифры. Файлы `photos/review_01.jpg … review_14.jpg` (600×600, уже квадратные, лицо в центре). Оптимизировать под web (WebP/JPG, ≤40 KB), сделать @2x. Номер кейса можно оставить маленьким бейджем или убрать совсем — фото важнее.
- **Ниша** — одна строка, при переполнении обрезать с «…».
- **Точка А / точка Б** — короткие фразы, 1–3 строки. Точка Б всегда визуально сильнее (вес шрифта, цвет).
- **Цитата** — курсив, в «ёлочках», как в макете.
- **Кнопка «Открыть отзыв ↗»** — ведёт на `url` ниже.
- Карточки одной высоты; текст выравнивать по верху, кнопку прижимать к низу.
- Порядок карточек — как ниже (1 → 14).

## 6. Техника

- Карточки — компонент с пропсами `{photo, name, niche, before, after, quote, url}`; данные — массив из 14 объектов (можно сгенерировать из xlsx).
- Карусель: горизонтальный скролл со snap, стрелки ‹ › работают, на мобиле — свайп, ширина карточки ~85vw.
- Все ссылки `target="_blank" rel="noopener"`.
- Фото — `<img>` с `alt="Фото: Имя Фамилия"`, `loading="lazy"`, WebP + fallback JPG.
- Палитра, шрифты, скругления и отступы — 1:1 из существующего макета (кремовый фон, тонкие золотистые разделители, serif-заголовки, гротеск в тексте). Ничего нового не вводить.
