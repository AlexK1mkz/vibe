# Заявки в Google-таблицу

Таблица: **ZhanaRu — заявки с сайта** —
https://docs.google.com/spreadsheets/d/1bOJzlk-rED_kU4cgv6BlAEtvtcw4Vji003ekIVj-sC4/edit

Колонки уже размечены: контакты, сегмент, индекс, зоны внимания, рекомендованный чекап, ответы теста
(включая рост, вес и ИМТ), UTM, «Статус» (выпадающий список) и «Комментарий куратора».

В таблице сведения о здоровье. Доступ к ней — только сотрудникам клиники, которые работают с заявками.

## Как подключить (один раз, ~5 минут)

1. Откройте таблицу → **Расширения → Apps Script**.
2. Удалите содержимое `Код.gs` и вставьте код из `google-sheets/Code.gs`. Сохраните.
3. **Настройки проекта (шестерёнка) → Свойства скрипта → Добавить**: `SECRET` = любая длинная случайная строка.
4. **Начать развертывание → Новое развертывание → тип «Веб-приложение»**:
   - «Выполнять от имени» — **от моего имени**;
   - «У кого есть доступ» — **все** (иначе сайт не сможет писать; без секрета скрипт заявку не примет).
5. Разрешите доступ к таблице и скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
6. На хостинге в `zhanaru-config.php` (или `api/private/config.php`) впишите:
   ```php
   'sheets_webhook' => 'https://script.google.com/macros/s/…/exec',
   'sheets_secret'  => 'та же строка, что в SECRET',
   ```
7. Пройдите тест на сайте до конца — строка должна появиться в листе «Заявки».

После правок кода в Apps Script нужно **Управление развертываниями → Изменить → Новая версия**, иначе работает старая версия.

## Если PHP на хостинге нет

Можно писать в таблицу прямо из браузера: оставьте свойство `SECRET` пустым и впишите адрес `…/exec`
в `src/content/site.ts` → `sheetsWebhook`, затем пересоберите сайт. Минус: адрес виден в коде страницы,
и кто угодно может отправить в таблицу мусор. Поэтому основной вариант — через `lead.php`.
