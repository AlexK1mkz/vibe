# Выкладка на Hoster.kz

## Автоматически (основной способ)

Сайт: **https://zhanaru.vip**, Plesk `pkz21.hoster.kz:8443`, папка `httpdocs`.

1. Правите исходники в `Zhanaru/web` и отправляете в `main` на GitHub.
2. GitHub Actions (`.github/workflows/zhanaru-deploy.yml`) прогоняет тесты, собирает сайт под `https://zhanaru.vip`
   и кладёт готовые файлы в ветку **`deploy-zhanaru`**. Если тесты упали — сайт не меняется.
3. GitHub шлёт webhook в Plesk → Plesk (Git для домена zhanaru.vip, ветка `deploy-zhanaru`, автоматическая выкладка)
   забирает ветку и обновляет `httpdocs`. Обычно 1–3 минуты от push до живого сайта.

Ход выкладки — вкладка **Actions** в репозитории; в Plesk — «Git» у домена (журнал и кнопка «Получить сейчас»).
Настройки заявок (`zhanaru-config.php`) лежат на хостинге **выше** `httpdocs` — выкладка их не трогает.

## Вручную (запасной способ)

Сайт статический, плюс один PHP-файл для заявок (`api/lead.php`). Node.js на хостинге не нужен —
подойдёт любой тариф виртуального хостинга с PHP 7.4+ (лучше 8.1–8.3).

## 1. Собрать архив (на своём компьютере)

```bash
npm install
npm run pack
```

Получится `deploy/zhanaru-site-ГГГГ-ММ-ДД.zip` — внутри всё содержимое сайта, включая скрытый `.htaccess`.

Если домен не `zhanaru.kz`, укажите его при сборке — от него зависят canonical, карта сайта, robots.txt и
предпросмотр ссылок:

```bash
SITE_URL=https://ваш-домен.kz npm run pack
```

В PowerShell: `$env:SITE_URL='https://ваш-домен.kz'; npm run pack`.

## 2. Залить на хостинг

1. Войдите в панель управления хостингом Hoster.kz → **Файловый менеджер**.
2. Откройте папку сайта (обычно `public_html` или `www/ваш-домен`). Удалите оттуда заглушку `index.html`, если она есть.
3. Загрузите zip-архив и распакуйте его **прямо в эту папку** (чтобы `index.html` лежал в корне, а не во вложенной папке).
4. Включите показ скрытых файлов и проверьте, что `.htaccess` на месте.

По FTP: загрузите содержимое архива в ту же папку (FileZilla → включить «Показывать скрытые файлы»).

## 3. Домен, HTTPS, PHP

- **SSL**: в панели включите бесплатный сертификат Let's Encrypt для домена и `www`. Редиректы http → https и
  www → без www уже прописаны в `.htaccess`.
- **Версия PHP**: в настройках сайта выберите 8.1 или новее. Нужны модули `curl`, `mbstring`, `json` (обычно включены).

## 4. Приём заявок

1. Создайте бота у @BotFather, добавьте его в чат клиники, узнайте `chat_id`.
2. Скопируйте `api/private/config.example.php` в файл `zhanaru-config.php` **на уровень выше папки сайта**
   (рядом с `public_html`, а не внутри) и заполните: токен и чат Telegram, почту, `allowed_origins`
   (`https://ваш-домен.kz`), адрес и секрет Google-таблицы.
   Если выше папки сайта файл положить нельзя — `api/private/config.php` (папка закрыта `.htaccess`).
3. Google-таблица: `google-sheets/README.md`.

## 5. Проверка после выкладки

- [ ] `https://домен/` открывается, http и www перенаправляют на https без www.
- [ ] `https://домен/robots.txt` и `https://домен/sitemap-index.xml` открываются.
- [ ] `https://домен/api/private/config.example.php` отдаёт 403.
- [ ] Пройти тест: после контактов в Telegram приходит «Новый лид», после теста — «Тест пройден», в таблице одна строка.
- [ ] Форма «Запись» внизу страницы — заявка приходит.
- [ ] Предпросмотр ссылки: https://developers.facebook.com/tools/debug/ → вставить адрес → «Scrape Again».
      Telegram: отправить ссылку боту @WebpageBot, чтобы обновить кеш. WhatsApp подхватит сам (кеш до суток).
- [ ] PageSpeed: https://pagespeed.web.dev/ — на локальной сборке было 95 (телефон) и 100 (компьютер).

## 6. Поисковики

**Google Search Console** (https://search.google.com/search-console):
1. Добавить ресурс «Префикс URL» → `https://домен/`.
2. Способ «Тег HTML»: скопировать значение `content` в `src/content/site.ts` → `verification.google`,
   пересобрать и залить; нажать «Подтвердить».
3. «Файлы Sitemap» → `sitemap-index.xml`.
4. «Проверка URL» → главная → «Запросить индексирование».

**Яндекс Вебмастер** (https://webmaster.yandex.ru):
1. Добавить сайт `https://домен/`.
2. «Мета-тег»: значение `content` → `verification.yandex` в `site.ts`, пересобрать, залить, подтвердить.
3. «Индексирование → Файлы Sitemap» → `https://домен/sitemap-index.xml`.
4. «Индексирование → Переобход страниц» → главная.
5. «Информация о сайте → Регион» → Астана.
6. Карточку организации в Яндекс Бизнесе и 2ГИС связать с сайтом (адрес и телефон должны совпадать с сайтом).

После каждой правки текстов: `npm run pack` → залить архив поверх. Файлы сборки с хешами в имени кешируются
браузером на год, HTML — нет, поэтому посетители сразу видят новую версию.
