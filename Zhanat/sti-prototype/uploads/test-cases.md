## Что проверяют кейсы

- **1** — эталон из методички, все пять расчётов
- **2** — три единицы: избыточная концентрация должна сработать
- **3** — возраст 26: миссия латентна, «включится через 7 лет»; почти пустая матрица
- **4** — 29 февраля високосного года: валидация даты; CS 29 → 11 → 2, двойная редукция; CS = M = 2 — синергия, отчёт должен это отметить; возраст 30, «через 3 года»
- **5** — день 31, максимальный; год 1975 — возраст 50
- **6** — пять девяток: избыток; PY = 1
- **7** — обычный кейс без особенностей, контроль стабильности
- **8** — возраст 16: миссия латентна, «включится через 17 лет»; шаг с доходом в этом возрасте — проверить, что интерфейс не ломается
- **9** — 22 в дне: не мастер-число, редуцируется в 4; Ь при транслитерации выпадает: GULNARA
- **10** — PY 6+6+1 = 13 → 4, проверить редукцию суммы

## Дополнительные проверки

| Проверка | Ожидание |
|---|---|
| Имя «Jean» латиницей | Считается как есть: J1+E5+A1+N5 = 12 → 3 |
| Имя «Александр», пользователь правит на ALEXANDER | Считается ALEXANDER: 1+3+5+1+1+5+4+5+2 = 27 → 9 Марс — показать, что написание меняет число |
| Имя «Қасым» | Q1+A1+S3+Y1+M4 = 10 → 1, казахские буквы транслитерируются |
| Имя «李» | Ошибка: введите имя латиницей или кириллицей |
| Имя «Анна-Мария» | ANNAMARIYA, дефис игнорируется: 1+5+5+1+4+1+2+1+1+1 = 22 → 4 |
| Дата `31.04.1990` | Ошибка валидации |
| Ввод `5121988` без точек | Маска приводит к `05.12.1988` |
| Дата 16.09.2026 | Ошибка возраста |
| Дата 16.09.1927 | Ошибка возраста (99+) |
| Все аспекты = 10 | Радар совпадает с внешним контуром, минимум не выделяется, сегмент cold |
| Все аспекты = 1, доход 30k+ | Сегмент hot |
| Доход «не буду указывать», средний 4 | Сегмент warm |
| Переключение `personal_year_mode` на birthday | Для 18.07.1989 на 16.09.2026 PY остаётся 8; на 01.03.2026 — считается по 2025 → 9+7+9 = 25 → 7 |
