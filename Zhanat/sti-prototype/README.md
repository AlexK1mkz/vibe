# Syucai Training Institute — прототип диагностики

Статический прототип: лендинг + диагностика (14 шагов) с мгновенным расчётом и отчётом.
Экспорт из Claude Design, подготовленный к публикации.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | лендинг |
| `diagnostika.html` | диагностика: 14 шагов → расчёт → отчёт → CTA |
| `calc.js` | расчётное ядро методики |
| `report-texts.js` | тексты интерпретаций отчёта |
| `support.js` | рантайм Claude Design |
| `vendor/` | локальные React и ReactDOM — без внешних CDN |
| `_ds/` | дизайн-система: токены и стили |
| `assets/` | изображения |
| `.nojekyll` | обязателен: без него GitHub Pages не отдаёт папку `_ds/` |

## Локальный запуск

Достаточно открыть `index.html` двойным кликом — сайт работает и по `file://`, и на любом статическом хостинге.

## Публикация

**GitHub Pages:** Settings → Pages → Branch `main`, папка `/ (root)`.

**Vercel:** Import Git Repository → Deploy. Framework Preset: Other.

## Ограничения прототипа

- Бэкенда нет: расчёт идёт в браузере, результаты нигде не сохраняются.
- `calc.js` и `report-texts.js` отдаются клиенту открытым текстом — методика видна любому, кто откроет исходники страницы. Закрытый репозиторий этого не меняет.
- CTA ведёт на `zhanatpower.com/customer/register` с параметрами результата в URL.
