# Диагностика «Твой код» — пакет для производства

Версия 1.0 · 16 сентября 2026 · Alex Kim, ТОО «Солтрикс»
Проект: Наука Сюцай / Жанат Кожамжаров / STI

Диагностика — **самостоятельная страница** (отдельный URL), не блок на главной. Главная zhanatpower.com ведёт на неё кнопкой; результат диагностики ведёт на подписку в приложении.

## Файлы

| Файл | Для кого | Что внутри |
|---|---|---|
| `spec.md` | продукт, дизайн, разработка | Экраны и поток: лендинг → тест → отчёт → CTA. Роли, интеграции, что считается заявкой |
| `methodology.md` | разработка, ИИ-агент, учитель на утверждение | Формулы, таблицы, диапазоны и интерпретации, шаблон отчёта, запреты |
| `flow.md` | разработка, аналитика | Переход на подписку: параметры, что видит клиент, связка покупки с результатом |
| `data-model.md` | разработка | Схема результата, колонки Google Sheets, события аналитики, payload в Telegram |
| `copy.md` | дизайн, копирайт | Все тексты интерфейса: экраны, кнопки, ошибки, письма |
| `report-prompt.md` | разработка ИИ-части | Готовый системный промпт для генерации отчёта |
| `test-cases.md` | QA, учитель | 10 контрольных дат с эталонными расчётами |
| `assets/` | дизайн | Фото Жаната для лендинга и отчёта |

## Что должен подтвердить учитель до релиза

1. Тексты интерпретаций в `methodology.md` — они сжаты из методички, нужна сверка.
2. Число Имени считается по **латинской таблице Жаната** (A I J Q Y = 1 … F P = 8). Кириллица транслитерируется автоматически и показывается пользователю для правки. Учителю подтвердить таблицу транслитерации.
3. Десять аспектов самооценки — формулировки вопросов.
4. Список запретов для ИИ-отчёта в `methodology.md`, раздел 9.

## Порядок производства

1. Утвердить `methodology.md` с учителем → 2. Дизайн по `spec.md` + `copy.md` → 3. Разработка расчётного ядра, прогон `test-cases.md` → 4. Подключение ИИ-отчёта по `report-prompt.md` → 5. Интеграции по `data-model.md` и `flow.md` → 6. Тест на 20 живых людях → 7. Релиз.
