## Версия 4: визуал 1:1 по референсу Уколовой

**Референс:** katty-crew.com/vv4. Сохранённая копия: `Уколова сайт пример/Все включено _ Масштабирование бизнеса за 4 месяца.html` + скриншот hero.
**Главное правило:** повторить референс **визуально и по структуре экранов** — тёмный люкс, огромная сжатая типографика, хром и золото, портреты с вырезанным фоном. Меняется только контент (под Жулдыз) и добавляются 2 тарифа, модалки оферты/политики и popup GetCourse.

## 0. ЧТО ИСПРАВИТЬ В ТЕКУЩЕМ МАКЕТЕ

Текущий макет (молочный фон, тонкий сериф, терракота, фото в скруглённой карточке) **не похож на референс. Переделать полностью:**

| Сейчас в макете | Должно быть (как у Уколовой) |
|---|---|
| Молочный фон по всей странице | Чередование: **чёрные** экраны (#080808 / #151515) и **белые** (#FFFFFF) |
| Тонкий сериф в заголовках | **Сжатый жирный гротеск, CAPS**, огромный кегль (hero — 250px) |
| Терракотовый акцент | **Золото #CEA275** |
| Заголовок hero обычным цветом | «ВСЁ ВКЛЮЧЕНО» с **хромированным градиентом** по буквам |
| Цифры обычным шрифтом | **Золотые рукописные цифры** (script) справа в hero |
| Фото в скруглённой рамке | **Портреты с вырезанным фоном** прямо на чёрном, частично перекрывают заголовок |
| Скруглённые pill-кнопки | **Белые прямоугольные кнопки** с иконкой ↗, CAPS |
| Шапка с меню | **Шапки нет.** Вместо неё — фиксированная **золотая полоса внизу экрана** «↗ Забронировать условия» |
| Нет фоновых надписей | На тёмных экранах — **гигантские полупрозрачные «призрачные» слова** за контентом |
| Скруглённые карточки 28px | Карточки почти без скругления (4–8px), тёмные #151515 или светло-серые #F8F8F8 |

## 1. ДИЗАЙН-СИСТЕМА (снята с референса)

### 1.1 Цвета (из CSS референса)
| Токен | Значение | Где |
|---|---|---|
| `--black` | #080808 | фон тёмных экранов |
| `--black-2` | #0E0E0E / #151515 | карточки на тёмном, тариф |
| `--graphite` | #1A1A1A / #292929 | «призрачный» фоновый текст, линии |
| `--white` | #FFFFFF | фон светлых экранов, кнопки |
| `--gray-card` | #F8F8F8 | карточки модулей |
| `--gold` | #CEA275 | акцентные слова, цифры, нижняя полоса, кнопки модулей |
| `--gold-dark` | #554636 / #342B22 | золото на тёмном в мелких элементах |
| `--text-dark` | #000000 | заголовки на белом |
| `--text-muted` | #9A9A9A / #B9B9B9 | подписи, лейблы |

**Хром для hero-заголовка (точно из референса):**
```css
background: linear-gradient(0.954turn, #A8A8A6 0%, #696969 25%, #F9F8F6 48%, #D4D4D4 69%, #7F7F7F 100%);
-webkit-background-clip: text; background-clip: text; color: transparent;
```
**Затемнение низа фото на чёрном:** `linear-gradient(0turn, #080808 0%, rgba(8,8,8,0) 100%)` на нижние 30% фото.

### 1.2 Шрифты
| Роль | Шрифт | Параметры |
|---|---|---|
| Display (все заголовки, CAPS) | **Oswald 700** (Google, кириллица). Если есть лицензия — Druk Cyr / Bebas Neue Pro Cyr | uppercase, line-height 0.9, letter-spacing −0.01em |
| Script (цифры в hero, подпись имени) | **Great Vibes** (Google, кириллица) | золото #CEA275 |
| Текст и интерфейс | **Inter** 400 / 600 / 700 | 16–20px, line-height 1.5 |

### 1.3 Кегли (desktop 1440 → mobile 375)
- Hero «ВСЁ ВКЛЮЧЕНО»: **250px** → 96px
- Подзаголовок hero (2 строки): **75px** → 40px
- H2 секций: **120px** → 48px
- «Призрачный» фоновый текст: **200px** → 80px, цвет #1A1A1A на #080808
- Цифры script в hero: **110px** → 56px
- Заголовки карточек: **38px** → 24px
- Текст: 18–20px → 16px; лейблы CAPS 14px, letter-spacing 0.08em

### 1.4 Приёмы, которые обязательно повторить
1. **Двухцветные заголовки:** часть слов золотом, часть чёрным (на белом) или белым (на чёрном). Пример: «**СТАНЬТЕ МАСТЕРОМ**» чёрным + «**К КОТОРОМУ ИДУТ**» золотом.
2. **Портреты с вырезанным фоном** (PNG без фона) на чёрном, крупно, частично перекрывают огромный заголовок (заголовок за фигурой, как «ВСЁ ВКЛЮЧЕНО» за Уколовой).
3. **«Призрачный» текст:** гигантские слова (например, «ГЛАВНЫЙ РЕЗУЛЬТАТ ПРОГРАММЫ») цветом #1A1A1A на #080808 за контентом.
4. **Белая прямоугольная кнопка** на всю ширину колонки: белый фон, чёрный текст CAPS 18px, иконка ↗ слева, высота 72px, скругление 2px.
5. **Золотая фиксированная полоса** внизу экрана: высота 32px, #CEA275, текст по центру «↗ Забронировать условия» 13px, вся полоса кликабельна (ведёт к тарифам).
6. **📌 эмодзи-булавка** как акцент возле карточек (как в референсе).
7. **Нумерация 01–08 / 01–03** мелко серым в углу карточек и строк.
8. Тонкие горизонтальные линии #E5E5E5 между строками списков на белом.

## 8. UX/UI — S-TIER 2026 (в рамках эстетики референса)

Эстетика референса сохраняется полностью; S-tier — это качество исполнения поверх неё:

**Движение**
- Hero при загрузке: «ВСЁ ВКЛЮЧЕНО» проявляется снизу маской по буквам (600ms), хром-градиент медленно «переливается» — сдвиг background-position 8s бесконечно, едва заметно.
- Фигура в hero — лёгкий параллакс при скролле (до 60px), заголовок уходит медленнее фигуры — эффект глубины.
- «Призрачный» текст на тёмных экранах едет горизонтально при скролле (scroll-driven, ±120px).
- H2 появляются построчно маской; карточки — fade + подъём 32px с каскадом 80ms.
- Цифры script в hero и «10 000+» считаются от 0 при появлении в зоне видимости.
- Белые кнопки: при наведении фон заливается золотом слева направо (300ms), стрелка ↗ сдвигается по диагонали на 4px.
- Строки таблицы «8 инструментов»: при наведении номер становится золотым, а строка слегка сдвигается вправо.
- `prefers-reduced-motion` — все анимации выключены, контент виден сразу.

**Качество**
- Fluid-кегли через `clamp()` между мобильными и десктопными значениями из §1.3.
- Контраст текста — не ниже WCAG 2.2 AA (серые подписи на #080808 не темнее #9A9A9A).
- Семантика: main / section с заголовками, один H1 («ВСЁ ВКЛЮЧЕНО»), alt у всех фото.
- Навигация с клавиатуры, видимый фокус (золотое кольцо 2px).
- Модалки на `<dialog>`, фокус заперт внутри окна.
- Производительность: LCP < 2.0s (hero-фото AVIF/WebP с `fetchpriority="high"`), CLS < 0.05, шрифты с `font-display: swap`, остальные фото с `loading="lazy"`, скрипт GetCourse — только по клику.
