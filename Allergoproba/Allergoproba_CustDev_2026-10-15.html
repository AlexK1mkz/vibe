Сводка

Гипотеза «Упростить выбор аллергенов при оформлении заявки» не подтверждена. Оба респондента считают выбор тарифа и аллергенов рабочим. Боль смещена: на точке забора — регистрация по ИИН и электронное согласие, в главном офисе — печать сопроводительных листов и серии препаратов.

Оговорка: оба респондента — опытные пользователи. Для новых клиник гипотеза остаётся открытой и проверяется в трёх оставшихся интервью.

Сильная сторона продукта: автоподтяжка данных пациента по ИИН из согласия. По оценке пользователя, по скорости Аллергопроба не уступает Брегис.

Топ-5 к доработке

  • P1 Пакетная печать сопроводительных листов по адресам ICE 75

  • P1 Автоподстановка лаборанта по логину ICE 60
  • P1 Сохранение добавленных вручную аллергенов ICE 60

Приоритеты фич на доработку

ICE = Impact × Confidence × Ease, шкала 1–5, максимум 125. P1 ≥ 50, P2 ≥ 30, P3 < 30. Ease — предварительная оценка, сверить с разработкой. Оценки можно менять в Excel, приоритет пересчитается.

F01 Пакетная печать сопроводительных листов по адресам
Back-office / приёмка · Фича
 Каждый адрес печатается отдельно: выбрать город → адрес → дату → открыть лист → открыть акт → печать → снять галочку → следующий. При ~200 пациентах по городу уходит 1–1,5 часа в день у администратора, параллельно с приёмом пациентов. Одна кнопка «Печать по адресам»: каждый адрес — отдельный блок с разрывом страницы, сортировка по маршруту курьера (левый берег, юго-восток…), только адреса с пациентами за дату. 5·5·3

F05 Регистрация по ИИН: ребёнок по согласию родителя + понятная ошибка
Регистрация · Фича
 Данные не подтягиваются, если ИИН в согласии с ошибкой или согласие подписал родитель на свой ИИН, а заявка на ребёнка. Для пользователя это выглядит как «зависание». Точки пишут Алишеру, он вручную проверяет согласия в Metabase. Поле «ИИН ребёнка» + ИИН и телефон родителя в согласии; при ненайденном согласии — понятное сообщение с причиной и поиском по ФИО/телефону вместо пустой формы. 4·4·4

F02 Справочник серий препаратов: одна активная серия на препарат
Выдача результатов · Фича
 В списке десятки устаревших серий, похожих друг на друга (отличается год). Сотрудники сверяют серии с Word-файлом, прыгают между экранами. Риск выбрать не ту серию, при проверке СЭС серия должна точно совпадать. Справочник «препарат → активная серия» с подстановкой по умолчанию, архив старых серий, обновление по итогам ревизии раз в полгода (ответственный — главный лаборант). 5·4·3

F04 Сохранение добавленных вручную аллергенов
Регистрация · Баг
 Препараты, которые пациенты приносят свои (например, артикаин другого производителя), добавляются в заявку, но на следующий день пропадают из списка — их вбивают заново. Сохранять пользовательские аллергены в справочник (с модерацией/дедупликацией), поиск по названию. 3·4·5

F06 Архивация неактивных адресов
Back-office / приёмка · Фича
 В списке адресов много неактивных точек (полгода без регистраций). Мешает печати и поиску ошибок. Авто-статус «неактивен» после N дней без регистраций, скрытие из списков по умолчанию. Связать с админкой адресов, которая уже в разработке. 3·4·4
48		 P2 Айгуль
F07 Упрощение электронного согласия для пациента
Согласие пациента · Фича
 Пациенты не понимают пункты (5 вопросов про хронические заболевания, инвалидность и т.д.), переспрашивают, забывают отметить принимаемые препараты. Пожилым сложно, старые телефоны не читают QR — администратор даёт свой телефон. Простые формулировки и подсказки, обязательный вопрос про препараты, крупный шрифт, альтернатива QR (ссылка по SMS или планшет на точке). 4·3·3
36		 P2 Айгуль
F08 Обработка недоставленных результатов в WhatsApp
Отправка пациенту · Фича
 4–5 случаев в день по Астане: статус «не доставлено» (ошибка WhatsApp Business, код уточнить). Администратор копирует номер, проверяет WhatsApp и отправляет вручную с рабочего телефона. Список недоставленных за день, кнопка «Открыть в WhatsApp», валидация номера при регистрации, расшифровка причины ошибки. 3·4·3

Выводы по методике

  • Выборка: проведено 2 из 5, обе — опытные пользователи. Новые клиники недоступны: одна не работает в программе, ещё одна не отвечает, медпредставитель не предупредил.
  • UX-задачу респонденты не выполняли — экран показывал Алишер. Замеров времени и кликов нет. Дальше: респондент сам шарит экран и оформляет тестовую заявку.
  • Второму респонденту не назначили время — ожидание и простой. Дальше: слоты по 15 минут в календаре.
  • Респондент на рабочем месте отвлекается — использовать аварийную версию на 7 минут (задача + «одна вещь»).
  • Интервью с администратором главного офиса заняло ~30 минут и дало больше всего фактуры. Для back-office закладывать отдельную встречу или визит в офис.
