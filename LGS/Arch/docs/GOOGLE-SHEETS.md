# Как подключить Google Таблицу

Сайт пишет каждую заявку строкой в Google Таблицу: клиентов на лист «Клиенты», специалистов на лист «Специалисты». Для записи нужен сервисный аккаунт Google: это технический пользователь, от имени которого сайт вносит строки. Создать его может только владелец аккаунта Google. Занимает около 10 минут.

Пока переменные не заданы, заявки сохраняются только в базу и видны в админке. Ничего не теряется: после подключения несинхронизированные анкеты специалистов допишутся в таблицу сами при следующем запуске крона.

## 1. Создайте таблицу

1. Откройте https://sheets.new и назовите таблицу, например «LGS заявки».
2. Переименуйте первый лист в `Клиенты`, добавьте второй лист `Специалисты`.
3. Скопируйте идентификатор таблицы из адреса: это часть между `/d/` и `/edit`.
   В адресе `https://docs.google.com/spreadsheets/d/1AbC…xyz/edit` идентификатор `1AbC…xyz`.

Заголовки колонок можно не вносить: порядок колонок описан в `integrations/sheets.ts` (`LEAD_HEADER` и `SPECIALIST_HEADER`). Если хотите заголовки, впишите их в первую строку в том же порядке.

## 2. Создайте сервисный аккаунт

1. Откройте https://console.cloud.google.com и создайте проект, например `lgs-site`.
2. В поиске консоли найдите **Google Sheets API** и нажмите **Enable**.
3. Откройте **IAM & Admin → Service Accounts → Create service account**. Имя: `lgs-sheets`. Роли проекта не нужны, пропустите этот шаг.
4. Откройте созданный аккаунт, вкладка **Keys → Add key → Create new key → JSON**. Скачается файл с ключом.
5. Скопируйте адрес аккаунта вида `lgs-sheets@lgs-site.iam.gserviceaccount.com`.

## 3. Дайте аккаунту доступ к таблице

В таблице нажмите **Настройки доступа**, вставьте адрес сервисного аккаунта и дайте роль **Редактор**. Уведомление можно не отправлять.

## 4. Задайте переменные в Vercel

В обоих проектах (`lgs-archetype` и `lgs-specialists`): **Settings → Environment Variables**.

| Переменная | Значение |
|---|---|
| `GOOGLE_SHEETS_ID` | Идентификатор таблицы из шага 1 |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | Содержимое скачанного файла с ключом целиком, одной строкой. Тип: Sensitive |

После сохранения перевыложите оба проекта: **Deployments → последний → Redeploy**.

Файл с ключом не кладите в репозиторий и не пересылайте в мессенджерах: он даёт право писать в таблицу.

## 5. Проверьте

Отправьте тестовую анкету на сайте специалистов и пройдите тест на клиентском сайте до формы контакта. В течение минуты в таблице появятся строки. Если строк нет, откройте в Vercel **Logs** и найдите строки с пометкой `[sheets]`: там будет причина. Чаще всего это не выданный доступ из шага 3 или не включённый API из шага 2.
