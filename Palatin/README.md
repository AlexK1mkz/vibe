# Palatin Group — прототип сайта

Статичный HTML-прототип для показа клиенту. Работает на GitHub Pages без сборки.

## Публикация на GitHub Pages
1. Создайте репозиторий, например `palatin-preview`.
2. Файлы сайта лежат в папке `Palatin/` репозитория `vibe`.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/palatin-preview/`.

## Страницы
- `index.html` — главная (9 bento-блоков, встроенный квиз)
- `podbor.html` — квиз отдельной страницей для рекламы (без меню)
- `katalog.html` — каталог с фильтрами (фильтры пишутся в URL: `?cat=keramogranit&effect=мрамор`)
- `product.html?id=…` — карточка товара: галерея, цена, наличие, калькулятор, QR
- `brand.html?b=peronda` — страница бренда
- `palatin-hill.html`, `stock.html` — линейки
- `dizayneram.html` — дизайнерам, прорабам и объектам (`#obektam`)
- `salony.html`, `o-nas.html` — салоны, компания и Кунсулу

## Что в демо, а что заглушка
- 70 реальных позиций из «Каталог 2026»: фото, названия, форматы и цены взяты из PDF.
- Заявки не уходят в CRM — после отправки показывается экран успеха. WhatsApp открывается по-настоящему.
- Помечены «демо» / «место под…»: портрет и видео Кунсулу, отзывы дизайнеров, остатки по салонам, 3D-визуализация.
- Нужно уточнить у клиента: часы работы салонов, единицу цены (м² / шт.), пороги бюджета квиза, процент партнёрской программы, даты истории.
